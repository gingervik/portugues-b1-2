# Português B1.2

Página do curso de português europeu (nível B1.2): aulas, gramática, léxico, textos, prática interativa e trabalhos de casa.

Страница курса европейского португальского B1.2: уроки, грамматика, лексика, тексты, интерактивная практика и домашние задания. Обновляется после каждого урока.

Сайт: https://gingervik.github.io/portugues-b1-2/

Всё в одном файле `index.html`, без сборки. Ответы в упражнениях сохраняются только в браузере того, кто их вводит.
